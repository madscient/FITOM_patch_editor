# fitom_patch_editor

FITOM_X 用のパッチ/プロファイルエディタです。FITOM_X が使う音色ファイル
(`*.profile.json` と、そこから参照される `*.patchbank.json` /
`*.hwbank.json` / `*.swbank.json` / `*.drumkit.json` など)を直接読み書き
します。FITOM_X を起動していなくても、音色の閲覧・編集・保存ができます。

FITOM_X が起動していれば、FITOM_X を通して音を確かめながら編集できます。
起動していないときは、普通の MIDI 出力ポートへ送って試聴することもできます。

## ビルド

必要なもの:

- CMake 3.20 以上(Visual Studio 2026 向けのプリセットを使う場合は 4.2 以上)
- C++17 に対応したコンパイラ
- [vcpkg](https://github.com/microsoft/vcpkg)。環境変数 `VCPKG_ROOT` に
  vcpkg の場所を設定しておくと、必要なライブラリは自動で取得されます。

```bash
cmake --preset vcpkg                 # Linux/macOS
cmake --build build/vcpkg
ctest --test-dir build/vcpkg --output-on-failure
```

Windows では、Visual Studio のバージョンに合わせてプリセットを選びます。

| プリセット | 対象 | ビルドの出力先 |
|---|---|---|
| `vcpkg-windows` | Visual Studio 2022 | `build/vs2022` |
| `vcpkg-windows-vs2026` | Visual Studio 2026(CMake 4.2 以上が必要) | `build/vs2026` |

```powershell
cmake --preset vcpkg-windows-vs2026
cmake --build build/vs2026 --config RelWithDebInfo
```

Visual Studio 2026 に付属する CMake(4.1.1)は `Visual Studio 18 2026` の
ジェネレータに対応していません。`cmake --version` が 4.2 より古い場合は、
[cmake.org](https://cmake.org/download/) から新しい CMake を入れて PATH を
通してください。

GUI を作らずデータの読み書き部分とテストだけをビルドしたい場合は、
`-DFPE_BUILD_GUI=OFF` を付けます。

## 起動

実行ファイルは `fitom_patch_editor_gui`(Windows では
`fitom_patch_editor_gui.exe`)です。実行ファイルと同じ場所にある `assets/` と
`spec/` のフォルダ(ビルド時に自動でコピーされます)を一緒に置いてください。
`spec/` が見つからないと、チップごとの値の範囲が分からないため、全項目を
暫定の範囲で表示し、警告を出します。

起動のしかたは3通りあります。

1. **引数なし**: メインメニューから始まります。プリファレンスで自動読み込みを
   設定していれば、そのプロファイルを開いた状態で始まります。
2. **プロファイルを指定**: そのプロファイルを開いた状態(アウトライン画面)で
   始まります。開けなかった場合はメインメニューにエラーを出します。
   プリファレンスの設定より優先されますが、プリファレンスの内容は変わりません。

   ```
   fitom_patch_editor_gui.exe "C:\path\to\some.profile.json"
   ```

3. **キオスクモード**: 1つのパッチの編集画面だけを、ウィンドウ全体に開きます。
   編集画面を閉じるとエディタも終了します。FITOM_X から起動するための
   使い方です。

   ```
   fitom_patch_editor_gui.exe <profile.json> <種別> <バンクファイル> <prog>
   ```

   | 種別 | バンクファイル | prog |
   |---|---|---|
   | `device` | `*.hwbank.json` | デバイスパッチの番号 |
   | `layered` | `*.patchbank.json` | レイヤードパッチの番号 |
   | `performance` | `*.swbank.json` | パフォーマンスパッチの番号 |
   | `drum` | `*.drumkit.json` | そのキットのプログラム番号(プロファイルの登録と一致している必要があります) |

   `pcmbank` と `samplezonebank` は将来のための予約語で、今は編集画面がありません。
   バンクファイルは、指定したプロファイルが実際に参照しているものでなければ
   なりません。引数に誤りがあると、エラーのダイアログを出して終了します。

## 使い方

### メインメニューとプロファイルの読み込み

- 「プロファイル読み込み」でファイルブラウザが開きます。フォルダを
  ダブルクリックで移動し、`*.profile.json` をダブルクリックで開きます。
  上のパス欄にフォルダを入力して「移動」でも移動できます。
- 「プリファレンス」で設定を開きます(下記)。
- 「新規プロファイル作成」「プロファイル削除」はまだ使えません。

### アウトライン

開いたプロファイルのバンクを一覧します。

- レイヤードパッチバンク、パフォーマンスバンク、デバイスパッチバンク、
  サンプルゾーンバンク、PCM 波形バンク、ドラムキットマップの順に並びます。
  デバイス・サンプルゾーン・PCM 波形はチップの種類ごとにまとまっています。
- バンクをクリックすると、その中身の一覧(バンク詳細)に移ります。
  「戻る (アウトライン)」で戻ります。
- 読み込みで問題があったファイルは「警告」に出ます。問題のあるファイルは
  読み飛ばし、残りはそのまま使えます。
- 「閉じる」でプロファイルを閉じてメインメニューへ戻ります。
- 「新規バンク作成」で新しいバンクのファイルを作ります。種別(レイヤード
  パッチ / デバイスパッチ / パフォーマンスパッチ / ドラムキット)、バンク名、
  ファイル名を入れます。デバイスパッチではチップの種類、ドラムキットでは
  routed / direct も選びます。バンク番号は自動で決まり、OK を押すとすぐに
  ファイルが作られます。

### パッチの編集

バンク詳細でパッチをクリックすると、そのパッチの編集画面が開きます。
編集画面はいくつでも同時に開けます。

どの編集画面にも、右上に次の2つのボタンがあります。

- **登録**: 編集した内容をファイルに保存して、画面を閉じます。キオスク
  モードでは、エディタも終了します(routed のドラムキットでは、ノートの
  編集画面が閉じるだけです)。FITOM_X が起動していれば、FITOM_X が読み込んでいる
  音色にも変更を送ります。ただし、新しく作ったバンクは FITOM_X を再起動する
  まで FITOM_X に認識されません。
- **リセット**: その画面を開いた時点の値に戻します。保存はしません。

「登録」を押さずに閉じた編集は保存されません。

**デバイスパッチ**(チップのパラメータ)

- チップの種類に応じて、そのチップが使う項目だけが表示されます。他の項目の
  設定しだいで今は効かない項目は、灰色になります。
- 名前の後ろに `*` が付いた項目は、チップにはあるものの FITOM_X がまだ
  対応していない項目です。値は編集でき、保存もされます。
- ALG(接続)や WS(波形)は、画像の左右の ◀ ▶ で切り替えます。
- 下の鍵盤(5オクターブ)をクリックすると、その音で試聴できます。左の
  Mod / Vol のレバーで CC#1 / CC#7 を送ります。FITOM_X に接続している間は、
  パラメータを動かすたびに変更を FITOM_X に送ります。
- 「登録」せずに閉じると、保存済みの内容を FITOM_X に送り直し、試聴の音を
  保存済みの状態に戻します。

**レイヤードパッチ**

- 名前、ポリ数、パフォーマンスパッチの参照と、各トーンレイヤー(有効/無効、
  音域、移調、音量・パンのオフセット、使うデバイスパッチ)を編集します。
- レイヤーの追加と削除はまだできません。

**パフォーマンスパッチ**

- ビブラート、トレモロ、ベロシティ感度などを編集します。LFO の波形は画像の
  ◀ ▶ で、モードはドロップダウンで選びます。
- LFO 波形の画像は仮のもの(番号だけ)です。

**ドラムキット**

- routed のキットでは、バンク詳細が 0〜127 の全ノートの一覧になります。
  - 割り当て済みのノートは、クリックで試聴、ダブルクリックでドラムノートの
    編集画面を開きます。「複製」で次の空きノートにコピーし、「削除」で
    消します。
  - 未割り当てのノートは薄く表示され、「作成」で新しく割り当てます。
  - 作成・複製・削除はすぐにファイルに保存されます。
- ドラムノートの編集画面では、名前、鳴らす元のパッチ(ソースパッチ)、
  鳴らす音の高さ(プレイノート)、微調整・パン・ゲートタイム、ノートごとの
  パフォーマンスパッチを編集します。
  - プレイノートは、ノート名(C4 = MIDI ノート 60)のドロップダウンか、
    「キーボードで選択」で開く鍵盤から選びます。鍵盤はクリックで試聴、
    ダブルクリックか「OK」で決定です。
  - 「試聴」ボタンを押している間、そのノートの音が鳴ります。
- direct のキットでは、バンク詳細の中でソースパッチと音域だけを編集し、
  「登録」で保存します。

### 参照の選び方(パッチピッカー)

パフォーマンスパッチ、トーンレイヤーのデバイスパッチ、ドラムノートの
ソースパッチなどの参照は、名前の表示をクリックするとピッカーが開きます。

- 種類(カテゴリ)→ バンク → パッチの順にたどります。「↑ 上へ」で1段
  戻ります。既に参照が設定されていれば、そのパッチの一覧から始まります。
- パッチをクリックすると試聴し、ダブルクリックか「OK」で決定します。
  「キャンセル」では何も変わりません。
- パフォーマンスパッチのピッカーには「参照解除」があり、参照を外せます。
- デバイスパッチとソースパッチのピッカーでは、カテゴリの最後に「無音」が
  あります。
- 参照の隣の「編集」ボタンで、参照先のパッチの編集画面を開けます。
  ROM 音色・内蔵リズム・無音・PCM 波形・サンプルゾーンのように、エディタで
  編集できない参照先では押せません。

### 試聴

試聴の音は次の順で送り先を選びます。編集画面に今の状態
(「試聴: FITOM_Xに接続済み」など)が出ます。

1. FITOM_X が起動していれば、FITOM_X に送ります。チャンネルは FITOM_X が
   自動で割り当てます。
2. FITOM_X が起動していなければ、プリファレンスで選んだ MIDI 出力ポートに
   送ります。
3. どちらも無ければ、試聴の音は出ません(編集と保存はできます)。

FITOM_X につなげるエディタは同時に16個までです。上限を超えるとメッセージを
出して終了します。

### プリファレンス

メインメニューの「プリファレンス」で設定します。

| 項目 | 内容 |
|---|---|
| 優先プロファイルフォルダ | 「プロファイル読み込み」で最初に開くフォルダ |
| 起動時にプロファイルを自動読み込み | オンにすると、次の項目のプロファイルを起動時に開きます |
| 自動読み込みプロファイルパス | 自動で開くプロファイル |
| 出力MIDIポート | FITOM_X が見つからないときの試聴の送り先 |
| 出力MIDI CH | 出力MIDIポートへ送るときのチャンネル(FITOM_X に送るときは使いません) |

フォルダやファイルの欄は、右の「参照...」で選べます。設定は実行ファイルと
同じフォルダの `FITOM_patch_editor.preference.json` に保存されます。

## 保存されるファイルについて

- 保存するのは、内容を変えたファイルだけです。編集していないファイルは
  書き換えません。
- デバイスパッチのファイル(`*.hwbank.json`)には、そのチップが使う項目だけを
  書きます。使わない項目でも、既定値以外の値が入っていれば残します。
- プロファイルのうち、エディタが扱わない設定(デバイス構成や MIDI 入力など)は
  そのまま残します。
- バンクファイルの先頭の階層にある、エディタが扱わない項目(説明用の `note` や
  `_comment` など)はそのまま残します。音色1つ分の中にある、エディタが扱わない
  項目は、そのファイルを編集して保存すると失われることがあります。
- 複数のプロファイルで共有しているバンク登録ファイル(`"banks"` に
  ファイル名を書く形)は書き換えません。そのプロファイルでの変更は
  `"bank_overrides"` に書きます。

## 今できないこと

- プロファイル自体の新規作成と削除。
- バンクやパッチの複製・削除(ドラムノートを除く)。
- レイヤードパッチのトーンレイヤーの追加・削除。
- PCM 波形バンクとサンプルゾーン(AWM)の中身の編集(閲覧のみ)。
- OPLL 系の ROM 音色専用の編集画面。
- direct キットの、ソースパッチと音域以外の項目の編集。
